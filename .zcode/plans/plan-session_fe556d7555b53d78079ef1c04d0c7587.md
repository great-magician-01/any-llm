# 双主题视图合并：一套视图 + 两层皮肤壳

## 结论先行

7 对视图差异极小（Upstreams 字节级相同，其余 5 对仅差 4–20 行 CSS/路由名，Login 差 108 行），脚本逻辑已 100% 走共享 composables/api。合并方案：**保留 `/` 与 `/glass` 双 URL 路由树（零链接破坏），两棵树指向同一套视图文件；视觉差异全部下沉到 CSS 变量 + glass.css 特例选择器；GlassShell 与两套 theme.ts 保留**。预计净删约 2500 行重复代码。

## 目标结构

```
web/src/views/                      # 新：唯一一套视图（8 文件，自 classic 迁移）
  Dashboard.vue / Upstreams.vue / Keys.vue / Usage.vue /
  Aliases.vue / Conversations.vue / Login.vue / Layout.vue   (+ 对应 .test.ts)
web/src/themes/classic/theme.ts     # 保留（App.vue 顶层 naive 覆盖）
web/src/themes/glass/theme.ts       # 保留（GlassShell 嵌套 provider 用）
web/src/themes/glass/glass.css      # 保留 + 新增少量变量覆盖/特例选择器
web/src/themes/glass/GlassShell.vue # 保留（嵌套 n-config-provider + 玻璃背景层）
```

删除：`themes/classic/views/`、`themes/glass/views/`、`themes/glass/GlassLayout.vue`、`themes/classic/Layout.vue`（Layout 也合一，两树共用）。

## 实施步骤

### 1. 基础层先行（不破坏现状）

- `utils/suite.ts` 新增两个纯函数 + 单测：`inGlass(route)`（`route.path.startsWith('/glass')`）与 `suitePath(route, path)`（glass 下加 `/glass` 前缀）。
- `style.css` `:root` 新增 classic 缺省变量（值 = 现 classic 视图中的硬编码值），light 模式块配对：
  - `--overlay-1: rgba(148,163,184,.1)`、`--overlay-2: rgba(148,163,184,.12)`（Keys/Aliases/Dashboard hover 覆盖色）
  - `--panel-bg`（classic 取 `var(--surface-2)`）、`--panel-blur: none`、面板分隔色（Conversations 侧栏面板）
  - `--sider-bg`：classic 的 brand 渐变（glass.css 已有同名变量）
- `glass.css` `.glass-root` 覆盖同名变量：`rgba(255,255,255,.06/.08)`、`--panel-blur: blur(14px)` 等（值 = 现 Glass* 文件中的硬编码值）；light 块 `:root[data-theme='light'] .glass-root` 配对覆盖。
- 一次性微差异（logout hover 色 `#fb7185→#fc8a9b`、suite-switch 圆角/内高光、Login 卡片表面）走 glass.css 既有模式：`.glass-root .类名` 特例选择器；凡 classic 侧存在 light 覆盖的，glass.css 用 `:root[data-theme='light'] .glass-root .类名` 配对特异性。

### 2. 迁移视图（git mv 保留历史）

`themes/classic/views/*.vue` 与 `themes/classic/Layout.vue` → `src/views/`，随后在每个视图内做三类替换：

- **CSS**：硬编码 rgba/blur → 上述变量；Login 卡片背景/边框 → 变量或 `.glass-root .login-card` 特例。
- **路由名 → 路径导航**：Dashboard 的 `router.push({name:'upstreams'})` → `router.push(suitePath(route,'/upstreams'))`；Layout 菜单 key 从路由名改为路径（`:value="route.path"`、`router.push(key)`，menu 高亮天然正确）；Layout logout 目标 `'/login'` → `suitePath(route,'/login')`；切换按钮文案动态化（`inGlass ? '切换到经典版' : '切换到液态玻璃版'`）；Login 的 `useLoginRedirect('/')` → `useLoginRedirect(suitePath(route,'/'))`。
- **Login 装饰 div**（`.orb-1/.orb-2/.grid-overlay`）保留在 DOM，glass.css 加 `.glass-root .orb, .glass-root .grid-overlay { display:none }` 隐藏（glass 背景由 GlassShell 提供）。Login 内硬编码的 `rgba(91,140,255,…)`/`rgba(123,163,255,…)`（恰为两套 --brand 的 rgb）改 `color-mix(in srgb, var(--brand) X%, transparent)` —— 顺手修复 EVA accent 下 Login 装饰仍为蓝色的小 bug（accents.test.ts 有对比度守卫，跑测试确认）。

### 3. 共享组件小改

- `components/BalanceBoard.vue`：`to` prop 从路由名改为路径（内部 `router.push(to)`），Dashboard 传入 `suitePath(route,'/upstreams')`。

### 4. 路由

`router.ts` 两棵树结构、路由名（`glass-*` 前缀）、守卫、`body.glass-mode` 切换全部不动；仅把所有 `component:` 指向 `@/views/*.vue`（glass 树：GlassShell → 共用 Layout → 共用 views）。

## 非目标（明确不做）

- 不抽 `useKeysPage`/`useUsagePage` 等页面级 composables（另一维度重构，合并已消灭双写）。
- 不合并/统一 URL（`/glass` 前缀、双路由树、`switchSuite` 均保留）。
- 不动两套 `theme.ts` 的 naive 覆盖值与 GlassShell 结构。
- Aliases 页仍无组件测试（现状空白，不在本次范围）。

## 风险与缓解

- **视觉回归**：所有变量值逐字取自现有 diff 清单（已逐一核对 classic/glass 两侧现值）；截图验证收尾。
- **light 模式特异性竞争**：glass.css 覆盖必须与 classic light 块特异性配对，实施时逐条核对。
- **测试路径断言面广**：8 个测试文件涉及 import 路径，随迁移全量更新。
